# Sección 5: Glosario y Notas Técnicas

Definición de conceptos arquitectónicos y técnicos clave utilizados en la captura de requerimientos:

- **CRM (*Customer Relationship Management*):** Plataforma de software orientada a la gestión integrada de las relaciones comerciales, ventas, seguimiento de prospectos y atención al cliente, cuyo fin es consolidar toda la interacción en una base unificada.
- **ERP (*Enterprise Resource Planning*):** Sistema de planificación de recursos empresariales encargado de centralizar y automatizar procesos contables, facturación, compras, inventarios y logística dentro de una organización.
- **API RESTful (*Representational State Transfer*):** Interfaz de comunicación basada en los estándares del protocolo HTTP (GET, POST, PUT, DELETE), con arquitectura sin estado (*stateless*) y payloads usualmente formateados en JSON, diseñada para interoperabilidad entre sistemas distribuidos.
- **OAuth 2.0:** Protocolo de autorización estándar de la industria que permite a aplicaciones de terceros obtener acceso limitado y seguro a servicios de usuario (por ejemplo, Google Workspace o Microsoft 365) mediante *tokens*, prescindiendo del almacenamiento de contraseñas.
- **RBAC (*Role-Based Access Control*):** Mecanismo de seguridad y control de acceso basado en roles que restringe o habilita operaciones en el sistema de acuerdo con las responsabilidades y privilegios asignados al perfil del usuario.
- **Uptime:** Métrica porcentual que mide el tiempo de disponibilidad efectiva e ininterrumpida de una infraestructura de software o servicio en la nube durante un periodo determinado (e.g., $99.5\%$ anual o mensual).
